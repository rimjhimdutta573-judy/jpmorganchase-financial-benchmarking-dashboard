# Data dictionary

| Field | Meaning |
| --- | --- |
| `Metric_ID` | Stable identifier used to link `QoQ_Summary` to `Raw_Data`. |
| `Category` | Economic grouping used for filtering and dashboard scope. |
| `Metric_Name` | Reported line-item description. |
| `Unit` | Reported scale, such as `$mm`, `$bn`, `%` or `#`. |
| `Basis` | Reported or managed basis, as disclosed. |
| `Source_Page` | Page in the official 2Q26 earnings supplement. |
| `2Q26` to `2Q25` | Reported period values retained for trend context. |
| `QoQ Growth %` | Derived 2Q26 versus 1Q26 change; sign changes are N/M. |

No third-party source files are included in this repository. All values should be checked against the official supplement before reuse.
